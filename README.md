# Student Management System (EduManage)

A modern, responsive, and intuitive web-based Student Management System built using pure semantic HTML5, CSS3, and Vanilla JavaScript with zero external frameworks or dependencies.

## 🌟 Key Features

- **Modern Top Navigation**: Clean, fixed navbar with smooth scrollspy section highlighting. No hidden sidebars or hamburger menus.
- **Light & Dark Theme Switcher**: Instant theme toggle with local storage persistence and automated system preference detection.
- **Interactive Student Directory**:
  - Live student counter badge.
  - Collapsible inline "Register New Student" card.
  - Client-side validation: duplicate student ID detection and regex email format verification.
  - "Clear Sample Students" functionality with empty state notice.
- **Curriculum & Courses Section**: Comprehensive course cards with department chips, semester durations, and credit allocations.
- **Institutional Inquiries & Web3Forms Integration**:
  - Asynchronous AJAX form submission directly to institutional inbox via Web3Forms API.
  - Visual loading spinner, status alerts, and error handling.
- **Fully Responsive**: Optimized for desktops, laptops, tablets, and smartphones.

## 🚀 Getting Started

### Local Setup
1. Clone this repository:
   ```bash
   git clone https://github.com/matheshb67-coder/Student_Management.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Student_Management
   ```
3. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

## 🌐 Free Hosting via GitHub Pages

You can host this static website live on the web in 3 simple steps:
1. Go to your repository on GitHub: `https://github.com/matheshb67-coder/Student_Management`
2. Click on **Settings** > **Pages** (under the "Code and automation" section in the left sidebar).
3. Under **Branch**, select `main` from the dropdown and leave the folder as `/ (root)`, then click **Save**.
4. Within 1-2 minutes, GitHub Pages will deploy your site live at:
   `https://matheshb67-coder.github.io/Student_Management/`
